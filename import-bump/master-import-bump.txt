Both `example`s in that file — the old multiplicative and the old additive statement,
applied to the moved/generated declarations — typecheck. The additive twin is now
generated by `@[to_additive]` instead of being written out by hand.

Note: the implicit `{α}` moves in front of `{x y : G}`, because in the stabilizer file
`G` and `α` are section variables. Nothing in Mathlib applies either lemma with `@` or
with named arguments (they are mentioned in no other file), so no call site is affected;
the whole-library build in §3 confirms this.
